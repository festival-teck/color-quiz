カラーコード（HEX）の読み方

「#1E50A2」のような6桁のコードから、どんな色なのかを読み取るコツを解説します。

カラーコードは「赤・緑・青」の量

ウェブで使われる #RRGGBB 形式のカラーコード（HEXコード）は、R（赤）・G（緑）・B（青）の3つの光の強さを、それぞれ2桁ずつ並べたものです。たとえば #1E50A2 なら、Rが 1E、Gが 50、Bが A2 です。

各2桁は 00（いちばん暗い）から FF（いちばん明るい）までの256段階で表されます。3色それぞれ256段階なので、表せる色は 256 × 256 × 256 = 16,777,216色になります。

16進数の数え方

カラーコードは16進数で書かれています。0〜9のあとに、A=10、B=11、C=12、D=13、E=14、F=15 と続きます。2桁の値は「左の桁 × 16 ＋ 右の桁」で10進数に直せます。

16進数計算10進数
000×16 + 00
808×16 + 0128（ちょうど中間）
A310×16 + 3163
C812×16 + 8200
FF15×16 + 15255（最大）

細かく計算しなくても、左の桁だけ見ればおおよその明るさが分かります。左の桁が 0〜3 なら暗め、8 前後なら中くらい、C〜F なら明るめです。

基本の色のコード

光の三原色は、混ぜるほど明るくなります。3色すべて最大なら白、すべて0なら黒です。

コード色R / G / Bポイント
#FF0000赤255 / 0 / 0Rだけ最大
#00FF00緑0 / 255 / 0Gだけ最大
#0000FF青0 / 0 / 255Bだけ最大
#FFFF00黄255 / 255 / 0赤＋緑
#00FFFFシアン0 / 255 / 255緑＋青
#FF00FFマゼンタ255 / 0 / 255赤＋青
#FFFFFF白255 / 255 / 255すべて最大
#808080灰色128 / 128 / 1283つが同じ値なら灰色
#000000黒0 / 0 / 0すべて0

コードから色を読み取る3つのコツ

  • いちばん大きい値が色の方向を決める：Rが大きければ赤寄り、Bが大きければ青寄り。2つが同じくらい大きければ、その中間（R＋Gなら黄、G＋Bなら青緑、R＋Bなら紫〜ピンク）になります。
  • 全体の大きさが明るさを決める：3つとも大きければ明るい色、3つとも小さければ暗い色です。
  • 最大と最小の差が鮮やかさを決める：差が大きいほど鮮やかで、差が小さいほど灰色に近い、くすんだ色になります。

実際に読んでみよう

浅葱色 #00A3AF

R=00（0）、G=A3（163）、B=AF（175）。赤がまったくなく、緑と青が同じくらい強いので青緑。どちらも中〜明るめなので、明るく澄んだ青緑になります。

紺色 #1A237E

R=1A（26）、G=23（35）、B=7E（126）。青が飛び抜けて大きいので青。ただし最大の青でも126と中くらいなので、暗い青＝紺色になります。

銀鼠 #9C9B94

R=9C（156）、G=9B（155）、B=94（148）。3つの値がほぼ同じなので灰色。わずかに青が小さい分、ほんの少し黄みのある灰色になります。

知っておくと便利なこと

  • 大文字・小文字は同じ：#1e50a2 と #1E50A2 は同じ色です。
  • 3桁の省略形：#F0A のような3桁は、各桁を2回ずつ繰り返した #FF00AA と同じ意味です。
  • 8桁のコード：#RRGGBBAA のように末尾2桁が付く場合、最後の2桁は透明度を表します。

クイズで試してみよう

「激ムズ」レベルでは、似ている4つのカラーコードから正解を選びます。まずいちばん大きい値で色の方向を絞り、次に全体の大きさで明るさを比べると、選択肢を減らしやすくなります。

「この色も256色あんの？」レベルでは、ほぼ同じに見える4色から、お題と同じ色を見分けます。1つの値が数段階違うだけの色は、肉眼ではほとんど区別できないこともあります。画面の明るさや設定でも見え方が変わるので、明るい画面で挑戦してみてください。
